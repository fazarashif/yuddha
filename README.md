# Yuddha

Aplikasi belajar catur (web + HP, PWA) dengan dunia wayang/Nusantara berbalut fantasi.
Belajar lewat cerita, berlatih lewat puzzle adaptif, dan diuji oleh penantang berkarakter.

Status: **tahap desain** — requirement sudah disepakati, belum ada kode aplikasi.
